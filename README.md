# Accessible Components Playground

A React + TypeScript playground exploring accessible UI components and keyboard interactions.

## Components

- **Modal Dialog:** ARIA roles, focus management, Escape dismissal and focus restoration.
- **Tabs:** Keyboard navigation, ARIA attributes and disabled tab handling.
- **Disclosure:** Expandable content with accessible button controls.
- **Radix / shadcn-style examples:** Dialog and Tabs for comparison.

## Tech Stack

React · TypeScript · Vite · Tailwind CSS · Radix UI

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Build

```bash
npm run build
```

## Purpose

Built to explore accessibility patterns, keyboard navigation, ARIA semantics and reusable React components.

**Note:** These are learning implementations. Test with assistive technologies before using in production.
